# 📝 QuotePro — Quote & Estimate Manager

A modern, responsive and local-first Quote & Estimate Management System designed for small businesses, freelancers, agencies and service providers who need to send professional quotes and track their status.

---

## 🚀 Live Demo

### 👉 [Open QuotePro](https://sujitgoshwami1-commits.github.io/quotepro-demo/)

No installation required.
Open the demo in a modern web browser and start testing.

---

## ✨ Features

### 📊 Dashboard
- Total quotes overview
- Accepted value
- Pending value
- Win rate

### 📝 Quote Management
- Create professional quotes/estimates
- Automatic quote numbering
- Customer selection
- One or more line items (description, quantity, price)
- Tax support
- Quote validity date
- Quote status tracking (Draft, Sent, Accepted, Rejected, Expired)
- Print-ready quote layout
- Search quotes by number or customer

### 👥 Customer Management
- Customer profiles
- Name, email and phone
- Quote history per customer

### 📈 Reports
- Total quoted value
- Accepted value
- Win rate (conversion of sent quotes to accepted)

### 💾 Data Management
- Browser LocalStorage
- Local-first operation, works offline
- JSON data backup
- No server or database required

### 📱 Responsive Design
Works on:
- Desktop
- Laptop
- Tablet
- Mobile

## 🚀 Run Locally
No PHP, MySQL or server is required for the current version.

Simply:
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. QuotePro will open in your modern web browser.

---

## 💻 Technology
QuotePro is built using browser-based technologies:
- HTML5
- CSS3
- JavaScript
- LocalStorage

The current version is designed to work without a backend database.

---

## 💾 Data & Backup
QuotePro uses browser LocalStorage.

This means:
- Data is stored locally in the browser.
- Data is not automatically synchronized between devices.
- Clearing browser data may remove locally stored information.
- Regular backups are recommended.

For a production SaaS version, a secure backend and database would be required.
